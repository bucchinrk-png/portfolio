About

自己紹介

劇場という現場には「予約」「備品管理」「勤怠」「経費精算」「会計」といった 業務の塊が日々発生していますが、その多くが紙やExcelで非効率に運用されている現実が ずっと気になっていました。

外注ではなく自分で解決しようと、AI（Claude）を相棒にしたバイブコーディングを習得。 現在は所属組織の業務管理システムを継続開発しながら、その経験を活かして LP制作・業務自動化・AI活用相談のお仕事を受託しています。

※私はエンジニア出身ではなく、AI支援を前提とした開発スタイルです。 そのため、決済・認証・個人情報の中核取扱いを伴うミッションクリティカル案件はお受けしておりません。

Services

承れる業務

LP・コーポレートサイト制作

React または HTML/Tailwind CSS で、レスポンシブ対応のサイトを制作します。 スマホ表示の最適化、お問い合わせフォーム連携まで対応可能。

業務自動化スクリプト

Excel処理、データスクレイピング、PDF処理、定型レポート生成など。 Python / TypeScript / Google Apps Script で対応します。

AI APIを使った業務ツール

ChatGPT / Claude API を組み込んだ小規模ツール開発。 チャットボット、文書要約、データ分類などの実装に対応。

AI活用相談

御社の業務の中で AI を使える箇所の洗い出し、プロンプト設計、 Claude のローカル運用支援など。「まず試してみたい」段階のご相談歓迎。

Why Me

私を選んでいただく理由

1

AI（Claude）との協働開発に習熟しています

プロンプト設計から実装、デバッグまで一貫してAIをペアプログラマーとして使うスタイル。 だから、同じ予算でも実装スピードと完成度を両立できます。

2

現場目線でシステムを設計できます

業務システムを「自分で運用する側」として作ってきた経験があるため、 現場で本当に必要な機能とそうでない機能を見分けながら設計できます。

3

納品後にクライアントが困らないことを最優先

動作確認・README整備を丁寧に行います。 「動いてるからOK」ではなく「引き継いだ人が触れる」状態で納品します。
